Что следует из проверки

На раннем периоде выбрана M3 · Календарь и тренд. На внешних 21 месяцах её scaled CRPS относительно M1 изменился на +10.2% в шкале улучшения. Покрытие 80% и 95% интервалов составило 93.8% и 98.5%. Выбор не изменялся после просмотра внешнего теста.

В posterior predictive checks M3 вне 95% интервала репликаций оказались 6 из 64 проверяемых сводок. Это указывает, какие свойства данных модель воспроизводит недостаточно; качество вероятностного прогноза следует оценивать вместе с этими несоответствиями. При увеличении числа частиц максимальная относительная разница средних месячных итогов M4 составила 2.4%; финальный Monte Carlo error включает неопределённость фильтров, а не только траекторий.

Прогноз относится к архивным счётчикам при сопоставимом измерении. Он не даёт причинного вывода о политическом курсе. Семантическая точность правил, ошибки ASR, длина транскриптов, зависимость между двумя людьми и модульное приближение M4 остаются ограничениями. Основные и расширенные контексты показаны раздельно.

Для месячных сумм интервалы основной M3 слишком узкие: фактическое покрытие составило 72.1% и 90.0% при номинальных 80% и 95%. У M4 оно ближе к номиналу: 77.9% и 91.8%. Ежедневная точность M3/M4 практически одинакова, но динамика лучше описывает часть неопределённости месячных сумм. Основной выбор M3 сохраняется по заранее заданному daily CRPS; интервалы не перекалибровываются на внешнем тесте. Это ограничение нужно учитывать при использовании месячных итогов.

Что зависит от способа измерения

Сомнительные ссылки и ошибки распознавания речи могут менять ряд ещё до моделирования. Расширенная версия включает неясные контексты и обучается отдельно с теми же настройками.

Согласованный прогноз

Число записей N → записи с упоминанием B | N → упоминания C = B + E | B

Для каждой траектории: 0 ≤ B ≤ N и C ≥ B. При B = 0 упоминаний тоже нет. Число записей N общее для обоих людей; будущий знаменатель прогнозируется, а не берётся из будущих данных.

M1 · Сопряжённая базовая модель

Постоянный Poisson-уровень числа записей; Binomial-доля записей с упоминанием; Poisson-добавка внутри положительных записей. Gamma- и Beta-априорные распределения обновляются аналитически.

M2 · Вариация между днями

Negative binomial для числа записей и повторных упоминаний; Beta-binomial для доли упоминающих записей. Полный статический posterior рассчитывается Metropolis–Hastings.

M3 · Календарная иерархия

Общий уровень, сжатые отклонения каналов, тренд, месяцы и дни недели, точные даты и соседние дни. Масштабы Normal-приоров заданы заранее; это частичный pooling с фиксированными гиперпараметрами.

M4 · Меняющийся уровень

К M3 добавлены случайные блуждания на log/logit-шкалах. Фильтр распространяет частицы, обновляет веса и ресэмплирует при ESS < половины числа частиц. Это явно модульное приближение, а не полный совместный Bayes.

Смесь · Неопределённость между моделями

Равновесная смесь выбирает целую траекторию из одной модели. Средние и квантили не усредняются отдельно; согласованность счётчиков сохраняется.

Проверка вычислений

Четыре цепи, rank-normalized split R-hat < 1,01, bulk/tail ESS ≥ 400. Отдельно проверены функции вероятности, градиенты, CRPS, хронология и все совместные траектории.

Ограничения и воспроизводимость

День определяется началом архивной записи в MSK. Учитываются все программы, реклама и повторы в другое время. Пропуски не заменены нулями. Это прогноз архивных счётчиков при сопоставимом измерении; он не предсказывает политический курс или причинный эффект событий. Семантическая точность правил не измерена независимой человеческой разметкой. M4 использует 365-дневное окно состояний и cut posterior. Между Лениным и Сталиным остаётся немоделируемая зависимость сверх общего N. DM-тесты с 21 блоком приблизительны; результаты скорректированы Holm. Месячные исходы оцениваются только при полном наблюдении месяца.
