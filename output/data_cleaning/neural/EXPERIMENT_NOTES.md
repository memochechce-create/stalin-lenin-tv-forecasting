# Отменённый эксперимент с нейросетевым различением контекстов

17 октября 2026 года пользователь попросила прекратить эксперимент и оставить прежний код. Рабочий конвейер восстановлен: `python analysis/prepare_clean_data.py` использует `mention_rules.py` (`context-rules-2`). Исправления выгрузки, покрытия UTC/MSK, дедупликация и календарные признаки сохранены. Нейросетевые предсказания не применялись к итоговому корпусу.

## Задача и вывод

По комментарию преподавателя пробовали отличать конкретное упоминание исторического лица от названия улицы, площади, учреждения, другого человека и подобных контекстов. Проверяли модели семейства BERT и pretrained decision/NLI-модели. Внешний генеративный LLM API не запускали. Получить убедительно проверенное улучшение рабочего метода не удалось; это результат данного пилота, а не доказательство непригодности нейросетей для задачи.

## Что проверили

Все доли ниже относятся к одной диагностической development-выборке из 21 сложного реального контекста. При разных схемах классов результаты напрямую несопоставимы.

| Вариант | Результат пилота |
| --- | --- |
| GLiNER2.5-multi-Decide, dynamic int8 | Все 21 контекст отнесены к неопределённым; 0/21 правильных шестиклассовых решений. Квантизация нарушила работу модели. |
| Та же модель, FP32 | Простые примеры работали; на реальных контекстах варианты окна 200 и 100 символов дали 10/21 и 9/21. Бинарная формулировка — 9/21, все решения «историческое лицо». |
| RuBERT tiny bilingual NLI без обучения | 3/21 при подробной схеме классов. |
| RuBERT base cased NLI без обучения | 6/21 при подробной схеме классов. Готовые NLI-гипотезы недостаточно различали тему текста и конкретное вхождение имени. |
| Дообученный tiny RuBERT, три класса | Лучший development-результат 17/21, macro-F1 0,792; бинарное решение 18/21. Прежние правила на этих же примерах тоже дали 18/21 бинарных решений, с другими ошибками. |
| Замороженный base RuBERT, признаки целевого фрагмента и логистическая регрессия | 16/21, macro-F1 0,764; бинарное решение 17/21. |
| Дообучение последних четырёх слоёв base RuBERT | Остановлено по просьбе пользователя после второй эпохи: 16/21, macro-F1 0,734. Эксперимент не завершён. |

У дообученной маленькой модели оставались содержательные ошибки: портрет на банкноте считался упоминанием лица, Сталина Данилова — Иосифом Сталиным, вымышленный пролив имени Сталина — исторической фигурой. Достаточных оснований заменить рабочие правила не получили.

## Ограничения проверки

- 63 контрольных контекста разметил основной LLM-агент: 21 development и 42 отложенных. Это не независимый человеческий эталон и не репрезентативная оценка всего корпуса.
- Для дообучения агент разметил 289 других контекстов; 7 неопределённых исключены, осталось 282. Отсеивались совпадения передач и общие последовательности из семи слов с контрольными контекстами.
- Итоговая оценка выбранной модели на отложенной выборке не завершена. В раннем GLiNER-эксперименте файл с test-предсказаниями был создан, но его результаты не использовали для выбора последующих моделей. Нельзя заявлять подтверждённую точность или независимое превосходство над правилами.
- Обучение и проверка выполнялись на CPU. Платный API не использовался. Полный проход моделей по 20 141 кандидату не запускался.

## Где сохранено

Диагностические результаты остаются в этой папке: `development_context_probe.json`, `tiny_nli_development.json`, `base_nli_development.json`, `training_report.json`, `supervised_development.json`, `span_training_report.json` и другие файлы пилота.

Экспериментальные скрипты, отдельные тесты, зависимости и разметка перенесены в `cancelled_experiment/`. Это архив незавершённой работы; расположение файлов изменено, самостоятельный запуск из архива не поддерживается. Они не импортируются рабочим конвейером. Загруженные веса и изолированные зависимости остаются в игнорируемых Git каталогах `analysis/models/` и `analysis/deps/`; обычный запуск их не использует и не запускает обучение.

Текущий метод остаётся предварительным: наличие работающих правил и структурных проверок не устанавливает их precision/recall. Возобновлять нейросетевой эксперимент автоматически не нужно.

## Проверка восстановления

После отката полный запуск подготовки завершился успешно: 114 829 проверенных источников, 20 141 кандидат, 5 484 строки итоговой таблицы; структурная валидация — PASS, ошибок нет. Все 14 тестов рабочего конвейера прошли. Контрольные суммы трёх итоговых файлов полностью совпали с результатами до нейросетевого эксперимента (см. `../validation.json`).
